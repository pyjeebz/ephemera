Ephemera

Share a file by link without uploading it first. The link streams straight from the sender's device, only the parts someone watches, and it expires.

This server is an Ephemera relay. It passes bytes between a sender and the people they share with. When a link expires, the relay drops everything it held for it.

Send a file from your browser, or use the ephemera command line.

Got a link? Open it as it was sent to you.
