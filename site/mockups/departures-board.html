Get started

Every sandbox departs on time.

Run dev servers, tests and coding agents in microVMs that start in 65 ms and are deleted when they finish. Outbound traffic is blocked unless you allow it. Each departure leaves a signed record.

AShort-lived

Everything departs

Sandboxes are deleted when the command ends, and none outlives its time limit. --timeout 10m stops a runaway command.

BLocked down

One exit, and it's checked

The VM has no network card. Traffic leaves through a proxy that allows only the hosts you list and logs every attempt.

CSigned

A record of every trip

Commands, connections and the deleted disk, signed by the host. ephemera verify checks it.
