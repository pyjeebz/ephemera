# Landing page mockups

Three light directions for the ephemera.run landing page. Open the HTML files in a browser; each is self-contained, with fonts from Google Fonts.

| File | Direction | Hero moment |
| --- | --- | --- |
| `ticket-office.html` | Sandbox as a printed ticket | The ticket prints, gets stamped as connections happen, then tears off, leaving the signed stub |
| `evidence-room.html` | Sandbox as a sealed evidence bag | Changing the exit code breaks the seal, showing what `ephemera verify` catches |
| `departures-board.html` | Sandboxes on a split-flap board | Rows flip in, and one sandbox departs while you watch |

All three share the same copy, use real benchmark numbers and the real install command, and hide a mayfly somewhere in the hero. Each is a hero plus one supporting section, not a finished page.
